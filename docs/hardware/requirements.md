# 硬件需求与选型指标

状态：第一台样机平台和主要接口已通过实机验证

## 先确定的使用形态

第一代优先评估桌面设备，放在键盘旁边使用。可穿戴形态留到验证“随时记录”需求之后。

## 必要硬件模块

- 近讲双麦克风或麦克风阵列。
- 阳光下可读、适合显示 3 至 6 行中文的屏幕。
- 开始/暂停、确认、撤回三个可盲操作的物理控制。
- USB-C 供电与调试。
- 蓝牙或 USB HID，用作系统级文字输入设备。
- Wi-Fi 或手机桥接，用于需要云端整理的模式。
- 明确的录音状态灯或屏幕提示。
- 本地安全存储和可恢复固件升级能力。

## 选型评价表

| 维度 | 权重 | 目标 |
|---|---:|---|
| 中文显示效果 | 15% | 3–6 行清晰可读，刷新无明显等待 |
| 语音采集 | 15% | 0.3–1.5 米近讲稳定，具备基础降噪 |
| 交互延迟 | 15% | 按下后 500 ms 内进入记录状态 |
| 连接能力 | 15% | BLE、USB，Wi-Fi 为优先项 |
| 开发成熟度 | 15% | SDK、驱动、OTA 和社区资料完整 |
| 功耗与散热 | 10% | 桌面常供电稳定，便携模式可扩展 |
| 成本 | 10% | 原型成本可控，量产有下降空间 |
| 供应与合规 | 5% | 器件可持续采购，认证路径明确 |

## 第一台样机平台

| 项目 | 已确认规格 |
|---|---|
| 主控 | ESP32-S3 N16R8（16 MB Flash、8 MB PSRAM） |
| 显示 | 1.54 英寸 TFT，ST7789，10 针上接接口 |
| USB 串口 | CH340K，Windows 当前识别为 COM5 |
| 电池 | 720 mAh，ZH1.5 接口 |
| 声音输出 | 外接扬声器，MX1.25 接口 |
| 扩展 | 预留一路 UART |
| 开源板型 | `zhengchen/1.54tft-wifi` |
| 已验证 | 屏幕、三个按键、麦克风输入、下载与恢复路径 |

本样机用于验证表达流程。语音识别和文字整理优先通过 Wi-Fi 交给电脑或云端完成，设备本身负责采集、状态显示、确认操作和结果展示。
