# 家庭试用计划

状态：草案

## 目标

验证产品是否降低表达压力，而不是只验证识别是否准确。

## 周期

建议先进行 7 天，每天 10 至 20 分钟。场景包括日记、回答开放题、描述一件事情和向家长说明需求。

## 每次记录

| 项目 | 记录方式 |
|---|---|
| 是否主动开始 | 是 / 否 |
| 是否需要成人提醒 | 次数 |
| 最长自然停顿 | 估计秒数 |
| 是否阅读整理稿 | 是 / 否 |
| 是否发现 AI 改错意思 | 是 / 否，记录例子 |
| 最终是否采用文字 | 全部 / 部分 / 未采用 |
| 孩子的主观感受 | 用孩子自己的话记录 |

## 访谈问题

- 哪一步让你觉得轻松？
- 哪一步让你觉得麻烦？
- 它有没有把你的意思说错？
- 你希望它等你多久？
- 你希望它提醒你，还是安静地等你？

## 伦理和隐私

- 测试前向孩子说明设备在做什么。
- 不在孩子不知情时录音。
- 只保留为改进产品所必需的记录。
- 分享问题案例时删除姓名、学校和家庭信息。
