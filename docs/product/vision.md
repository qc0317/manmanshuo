# 产品愿景

状态：草案

## 一句话定义

慢慢说是一台会等待的表达辅助设备：孩子先用自己的话说，设备帮助整理并显示文字，孩子确认后再输出。

## 首要用户

不擅长键盘输入、表达时需要较长思考时间、容易重复或难以组织顺序的学龄儿童。

## 核心问题

普通语音输入只把声音变成文字，没有解决停顿焦虑、口语重复、结构不清和 AI 改变原意的问题。慢慢说需要建立一个可见、可控的闭环：

```text
孩子表达 → 设备耐心等待 → 显示原话 → 轻度整理 → 孩子确认 → 输出文字
```

## 成功标准

- 孩子更愿意开始表达，而不是长时间面对空白文档。
- 相比键盘输入，完成相同内容所需的成人协助明显减少。
- 孩子会阅读并判断整理稿，而不是无条件接受。
- AI 不添加原话中没有的事实、观点和情绪。
- 使用一段时间后，孩子自己的口头表达结构有所改善。

## 不做什么

- 不做自动写作文或自动完成作业的工具。
- 不用“优秀、较差”等分数评价儿童表达。
- 不把流畅和速度作为唯一目标。
- 不默认进行全天候录音。
