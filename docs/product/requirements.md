# 第一阶段产品需求

状态：验证中

## P0：必须具备

| 能力 | 要求 | 验收方式 |
|---|---|---|
| 开始表达 | 一次明确操作即可开始 | 孩子无需成人解释即可启动 |
| 等待思考 | 停顿不自动结束 | 停顿 10 秒后仍可自然续说 |
| 原话展示 | 原始转写始终可查看和修改 | 整理前后可以对照 |
| 轻度整理 | 去口头语、重复和明显病句 | 不新增观点和事实 |
| 意思确认 | 输出前由孩子主动确认 | 未确认不得进入最终输出 |
| 撤回修改 | 可以继续补充或退回原话 | 最多一次操作回到编辑状态 |
| 隐私提示 | 清楚显示是否正在录音 | 孩子和旁人都能看懂状态 |

## P1：验证后考虑

- 分句卡片与顺序调整。
- “为什么”“接下来呢”等温和追问。
- 个人词库和常见人名纠正。
- 朗读整理结果。
- 通过蓝牙 HID 输入当前电脑或平板光标位置。

## 体验指标

- 从按键到开始记录：目标小于 500 毫秒。
- 停止表达后出现转写：目标小于 1 秒。
- 整理结果出现：目标小于 3 秒。
- 一次确认流程：不超过 3 个主要操作。
- 连续一周仍能主动使用：每天至少 5 次是强需求信号。
