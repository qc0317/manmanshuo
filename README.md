# 慢慢说 ManManShuo

一个帮助孩子把“慢慢想、慢慢说”转化为清晰文字的表达辅助项目。

产品不替孩子生成观点，而是完成四件事：完整倾听、允许停顿、轻度整理、让孩子确认文字仍然代表自己的意思。

## 体验 Web 原型

直接打开 `dist/index.html`，或在该目录启动任意静态网页服务。

目前浏览器支持时可以使用中文语音识别；不支持时，可以点击“放入一段示例”体验完整流程。当前整理逻辑是本地规则，仅用于验证交互，并不代表最终 AI 效果。

## 三阶段路线

### 1. 先验证表达体验

通过 Web 原型确认孩子是否愿意使用、能否理解对照稿，以及产品是否真正减少表达压力。

### 2. 再选择硬件（已完成首台样机）

依据真实使用数据决定屏幕、麦克风、联网方式、算力、电池和成本，不先锁定芯片。

### 3. 最后制作固件（进行中）

硬件定型后实现录音、状态显示、按键、配网、升级和文本输出，并保留离线与隐私能力。

## 核心原则

1. 孩子的意思优先于文字的漂亮程度。
2. 默认只整理，不添加孩子没有表达过的内容。
3. 停顿不是错误，设备必须耐心等待。
4. 孩子拥有最终确认权和撤回权。
5. 儿童录音默认不长期保存。
