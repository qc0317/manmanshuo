# 固件

第一台样机平台已确定为正辰 1.54 英寸 ESP32-S3 N16R8，板级引脚、下载方式和原固件备份均已确认。

## 第一版可烧录程序

`esp32-s3/` 是当前样机的可烧录程序。屏幕、供电保持、三个实体按键和 INMP441 麦克风输入已经通过实机验证；当前版本实现“按住主键倾听、松开后处理、自动回到待机”的交互骨架。

## 已确认的样机硬件

- ESP32-S3，16 MB Flash，8 MB PSRAM。
- 1.54 英寸 ST7789 TFT。
- CH340K USB 串口，当前为 COM5。
- 720 mAh 电池和外接扬声器。
- 对应开源板型：`zhengchen/1.54tft-wifi`。

## 已确认引脚

```text
麦克风 I2S: WS=4, SCK=5, DIN=6
扬声器 I2S: DOUT=7, BCLK=15, LRCK=16
按键: BOOT=0, VOL+=10, VOL-=39
ST7789: MOSI=41, SCLK=42, DC=40, CS=21, RST=45, BL=20
电源保持=2, 电池/充电检测=9
```

参考实现：[zhengchen/1.54tft-wifi](https://github.com/78/xiaozhi-esp32/tree/main/main/boards/zhengchen/1.54tft-wifi)。板型由原厂 Flash 备份中的程序标识交叉确认；屏幕红、绿、蓝、白循环测试已在样机通过。

## 计划模块

```text
audio/       音频采集、缓冲和降噪前处理
display/     屏幕渲染、中文字体和状态提示
input/       物理按键、旋钮和长按操作
transport/   BLE、USB、Wi-Fi 与手机桥接
hid/         向电脑或平板输入确认后的文字
storage/     本地配置、词库和临时音频
update/      安全升级、回滚和恢复模式
app/         产品状态机与模块编排
tests/       硬件在环与核心状态测试
```

## 核心状态机

```text
待机 → 倾听 → 等待思考 → 转写 → 整理 → 等待确认 → 输出
                  ↑                    ↓
                  └──── 继续补充 / 撤回 ┘
```

## 固件红线

- 录音状态必须始终可见。
- 网络不可用时仍能安全退出、查看状态和保留必要内容。
- 升级失败不得导致设备永久无法启动。
- 音频保存策略必须可配置且默认最小化。
- AI 结果和原始转写必须可区分，不允许静默覆盖。
