# 固件

当前阶段只定义架构边界，硬件选型完成后再初始化具体 SDK 工程。

## 计划模块

```text
audio/       音频采集、缓冲和降噪前处理
display/     屏幕渲染、中文字体和状态提示
input/       物理按键、旋钮和长按操作
transport/   BLE、USB、Wi-Fi 与手机桥接
hid/         向电脑或平板输入确认后的文字
storage/     本地配置、词库和临时音频
update/      安全升级、回滚和恢复模式
app/         产品状态机与模块编排
tests/       硬件在环与核心状态测试
```

## 核心状态机

```text
待机 → 倾听 → 等待思考 → 转写 → 整理 → 等待确认 → 输出
                  ↑                    ↓
                  └──── 继续补充 / 撤回 ┘
```

## 固件红线

- 录音状态必须始终可见。
- 网络不可用时仍能安全退出、查看状态和保留必要内容。
- 升级失败不得导致设备永久无法启动。
- 音频保存策略必须可配置且默认最小化。
- AI 结果和原始转写必须可区分，不允许静默覆盖。
