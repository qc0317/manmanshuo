# 固件

第一台样机平台已确定为 ESP32-S3 N16R8。当前先核对开发板引脚和原固件分区，再初始化具体 ESP-IDF 工程。

## 已确认的样机硬件

- ESP32-S3，16 MB Flash，8 MB PSRAM。
- 1.54 英寸 ST7789 TFT。
- CH340K USB 串口，当前为 COM5。
- 720 mAh 电池和外接扬声器。
- 麦克风、按键、显示和音频 GPIO 待供应商资料确认。

## 计划模块

```text
audio/       音频采集、缓冲和降噪前处理
display/     屏幕渲染、中文字体和状态提示
input/       物理按键、旋钮和长按操作
transport/   BLE、USB、Wi-Fi 与手机桥接
hid/         向电脑或平板输入确认后的文字
storage/     本地配置、词库和临时音频
update/      安全升级、回滚和恢复模式
app/         产品状态机与模块编排
tests/       硬件在环与核心状态测试
```

## 核心状态机

```text
待机 → 倾听 → 等待思考 → 转写 → 整理 → 等待确认 → 输出
                  ↑                    ↓
                  └──── 继续补充 / 撤回 ┘
```

## 固件红线

- 录音状态必须始终可见。
- 网络不可用时仍能安全退出、查看状态和保留必要内容。
- 升级失败不得导致设备永久无法启动。
- 音频保存策略必须可配置且默认最小化。
- AI 结果和原始转写必须可区分，不允许静默覆盖。
